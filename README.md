# 📻 Valério Rádio Web

Site oficial da **NTP Rádio Web**, desenvolvido para transmissão online, divulgação da programação e interação com os ouvintes.

---

## 🎙️ Valério Rádio Web

Uma rádio feita para levar:

- 🎵 Música
- 📰 Informação
- 🎙️ Entretenimento
- 📻 Programação ao vivo
- 📱 Conteúdo para celular
- 🌐 Transmissão pela internet

---

# 🚀 Recursos do site

O projeto possui:

✅ Página inicial profissional  
✅ Design moderno em roxo  
✅ Layout responsivo para celular  
✅ Menu de navegação  
✅ Player de rádio personalizado  
✅ Botão Play/Pause  
✅ Controle de volume  
✅ Botão Mute  
✅ Compartilhamento da rádio  
✅ Indicador AO VIVO  
✅ Animações  
✅ Equalizador animado  
✅ Programação da rádio  
✅ Área de destaque  
✅ Área de contato  
✅ Instagram  
✅ WhatsApp  
✅ Compatibilidade com GitHub Pages
